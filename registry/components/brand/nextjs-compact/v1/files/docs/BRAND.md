# Brand

Product / organization identity lockup.

## Purpose
Display a brand mark, wordmark, or combined lockup that can navigate home or identify the product.

## Anatomy
- Mark (optional symbol)
- Name
- Descriptor (optional)

## Variants
- layout: `symbol` | `wordmark` | `lockup` | `stacked`
- tone: `color` | `monochrome` | `inverse`
- size: `sm` | `md` | `lg`

## Accessibility
Always provide `label`. When interactive, renders as link or button with focus-visible ring.

## Anti-patterns
- Do not use for arbitrary images.
- Do not omit accessible name when using symbol-only layout.
