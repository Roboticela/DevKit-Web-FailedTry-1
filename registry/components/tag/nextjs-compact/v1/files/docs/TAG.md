# Tag

Compact category / filter chip. Distinct from Label and Badge.

## Variants
size `sm`|`md`; tone `neutral`|`accent`|`positive`|`warning`|`negative`; selected; removable.

## Composition
Use `Tag.Group` for clusters.

## Anti-patterns
- Do not use Tag as a page heading.
- Do not replace Badge counts on icon buttons with Tag.
