# DevKit Playground

```bash
npm install
npm run dev
```

Opens **http://localhost:5173**

- **Breakpoint Lab** — semantic xs→3xl, live snapshot, capabilities, container queries
- **Visibility Lab** — viewport presets, modes, roles/flags, lazy + intersection
- **Aspect Lab** — presets (1:1 → A4/mobile), custom ratio, fit/crop, skeleton, responsive
- **Safe Area Lab** — live insets, edges, nav/FAB/keyboard modes, `useSafeArea` hook
- **Surface Lab** — roles, materials, elevation 0–5, outline/press, floating layers, modal overlay
- **Section Lab** — header/body/footer, collapse, sticky, empty/loading, nested hierarchy, visibility
- **Spacer Lab** — token presets, grow/adaptive, separators, safe-area (debug tint on)
- **Flex Lab** — grow/shrink/basis, responsive maps, semantic presets (navbar, toolbar, form-row, …)
- **Stack Lab** — vertical / horizontal / inline, responsive direction, separators, animate, virtual
- **Container Lab** — width variants, nested rhythm, custom max-width, overflow
- **Icon Lab** — searchable registry, variants, categories, buttons, status, badges
- **Motion Lab** — enter presets, stagger, hover/press, loading, skeleton, reduced-motion
- **Elevation Lab** — levels 0–5, semantic roles, hover/press, adaptive dark shadows
- **Shape Lab** — radius scale, semantic roles, circle/pill/avatar, nested radii
- **Theme Lab** — system/manual themes, custom Midnight, runtime accent vars
- **Spacing Lab** — scale, semantic roles, density modes
- **Grid Lab** — responsive columns, equal height, autofit, nested, masonry
- **Typography Lab** — full type scale
- **Color Lab** — semantic color themes
- **Layer 1 Catalog** — all 100 foundation packages
