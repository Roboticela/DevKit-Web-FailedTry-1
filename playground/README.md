# DevKit Playground

Browse registry components, pages, and scaffolds with live previews, docs, variants, and copyable source.

```bash
npm install
npm run dev
```

Opens **http://localhost:5173**

- Search and filter by Components / Pages / Scaffolds
- Open any card for Preview, Docs, Variants, Playground, and Code
- Light / dark appearance and 20 accent colors (saved in `localStorage`)
- UI chrome is composed from registry packages only
